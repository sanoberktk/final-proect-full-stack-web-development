# Personal Web Development Portfolio

A responsive portfolio project built with HTML, CSS, and JavaScript.

## Features
- Home, About, Projects, and Contact sections
- Responsive navigation menu for small screens
- Responsive project cards using CSS Grid
- Flexbox-based layouts and reusable CSS variables
- Contact form validation and `mailto:` message preparation
- Accessible labels, focus styles, and reduced-motion support

## Customize before submitting
1. Replace **Your Name** with your name.
2. Update `your.email@example.com` in `index.html` and `script.js`.
3. Replace the generic GitHub links with your real profile and project repository URLs.
4. Make sure each project listed reflects work you actually completed.
5. Test on a phone and desktop before publishing.

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, and this README.
2. In the repository, open **Settings → Pages**.
3. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the deployment and copy the published website URL from the Pages settings.
