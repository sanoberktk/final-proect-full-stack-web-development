PROJECT SUMMARY (100–150 words)

I created a personal web development portfolio with Home, About, Projects, and Contact sections to introduce my learning journey and showcase my course projects. I used HTML5 to organize the page, CSS3 to style it, and responsive design techniques—including Flexbox, CSS Grid, and a media query—to make it work on phones, tablets, and desktops. I used JavaScript to create a mobile navigation menu, update the footer year automatically, and validate the contact form before preparing a message in the visitor's email app. The project cards highlight a product landing page, an interactive to-do list, and this portfolio. One challenge was arranging the content so that the layout stayed readable on smaller screens. I addressed this by adjusting the grid into a single-column layout at mobile sizes and checking spacing, text size, and navigation behavior. I plan to publish the project with GitHub Pages.
